# Student Management System Using Python and Streamlit

## Project Overview

The Student Management System is an interactive web application developed using Python and Streamlit. The project demonstrates fundamental and advanced Python programming concepts through a practical student management application.

It is designed as an educational project to help students understand how Python concepts can be integrated into a real-world application.

## Objectives

- Demonstrate Python programming fundamentals.
- Implement Object-Oriented Programming (OOP) concepts.
- Apply functional programming techniques.
- Work with Python data structures.
- Perform file operations.
- Develop and deploy an interactive web application using Streamlit.

## Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/student-management-system.git
```

**Step 2: Navigate to the project folder**

```bash
cd student-management-system
```

**Step 3: Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**Step 4: Run the application**

```bash
python -m streamlit run app.py
```

The application will open in your browser at:

http://localhost:8501

## Deployment

The application can be deployed using Streamlit Community Cloud.

1. Upload the project to GitHub.
2. Visit https://share.streamlit.io.
3. Connect your GitHub repository.
4. Select `app.py` as the main application file.
5. Click Deploy.
